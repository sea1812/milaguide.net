DataSync Proは、異種データベース間でシームレスなリアルタイム同期を提供します。

## 対応データベース

- PostgreSQL
- MySQL
- MongoDB
- Redis
- Elasticsearch

## クイックスタート

```bash
npm install datasync-pro
```

## ユースケース

- ディザスターリカバリー
- リードレプリカ設定
- データセンター間レプリケーション
- ダウンタイムなし移行
